# Jayra One Space

## Windows-এ চালাও

1. ZIP extract করো। সফটওয়্যার খোলার জন্য ল্যাপটপে Node.js লাগবে।
2. `Start-Jayra.cmd` চালিয়ে ব্রাউজারে `http://127.0.0.1:4173` খোলো।
3. কমান্ড লেখো, অথবা **মাইকে বলো** চেপে মাইকের অনুমতি দাও। **ভয়েস চালু করো** বাটনটি ব্রাউজারে বাংলা ভয়েস পাওয়া গেলে কাজ করবে। **Always Talk** চালু করলে খোলা ট্যাবে উত্তর দেওয়ার পর Jayra আবার শুনতে চেষ্টা করবে।
4. **১০ সেকেন্ডের ডেমো** চাপো। সময় হলে Jayra নিজে থেকে কথা শুরু করবে। ভয়েস চালু থাকলে মুখে বলবে। এরপর লিখে বা বলে দেখো “আর পাঁচ মিনিট”।
5. “ক্যালকুলেটর খোলো” বা “নোটপ্যাড খোলো” বলে Windows অ্যাপ চালু করার চেষ্টা করো।

শুধু চ্যাট ও রিমাইন্ডার দেখতে `index.html` সরাসরি খুলতে পারো। সেই পথে মাইকের সমর্থন ব্রাউজারভেদে বদলাতে পারে। ভয়েস শনাক্তকরণের জন্য ব্রাউজার তার নিজস্ব অনলাইন সেবা ব্যবহার করতে পারে। বাংলা ভয়েস না পাওয়া গেলে উত্তর চ্যাটে দেখা যাবে।

## বর্তমান ডেমোর পরিধি

নির্দিষ্ট কমান্ড, সময়ভিত্তিক রিমাইন্ডার এবং রিমাইন্ডারের পর “আর পাঁচ মিনিট” বোঝে। রিমাইন্ডার ওই ব্রাউজারে সেভ হয়। ট্যাব বন্ধ থাকলে সময়মতো ডাকতে পারে না। ট্যাব আবার খুললে বাকি বা সময় পেরিয়ে যাওয়া রিমাইন্ডার দেখায়। Always Talk এই ট্যাবের ভেতর চলে। Windows অ্যাপ চালাতে লোকাল সার্ভার প্রয়োজন।

ভয়েস কমান্ডের বাইরের খোলামেলা আলাপ, ক্যামেরা এবং VS Code চালানোর কমান্ড এই সংস্করণের পরের কাজ।
